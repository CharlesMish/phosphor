Keyboard: R repeats the armed pluck. Esc stops. Buttons work with Enter and Space.

The tone is a Karplus–Strong delay line: one buffer, an allpass so the loop matches the note, a two-point average, and a gain for decay. Pluck position sets the width of one rectangular pulse. Pulling farther sets how strong that pulse is. A new pluck replaces the last one.

Both ends of the drawing are the same bright pluck. This string has no separate bridge pickup, no body, and no sampled recording. After a pluck, the curve is a slow sketch — about eight wiggles a second — scaled by the audio level, so the ring-down is visible. It is not moving at the note’s pitch, it is not the delay line, and it is not a prediction of a built instrument. Phosphor’s curve is a repeating waveform you draw; this pulse is a one-time pluck.
