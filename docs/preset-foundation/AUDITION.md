# Five-minute first audition

Use a comfortable, fixed monitor setting. This is a four-sound proof collection, not the later six-sound contributor banks. No listening approval has been claimed.

1. **0:00–1:00 — Find and play.** Open Sounds. Try `warm keys`, then clear the search. Load each role; your existing take and tempo remain. Play a few keys in the shown MIDI range. Use the keyboard octave buttons if needed. Factory originals are protected.
2. **1:00–2:00 — Short versus held.** Try the bass around C2 and keys around C3. Hold a note or chord, then release it. These sustain while held; the keys patch is synthetic, not a piano, and a short release is not a pluck envelope.
3. **2:00–3:00 — Static versus Motion.** Load the pad. Leave your tempo or explicitly choose its suggestion. Play Static demo, then Motion demo. Static disables shared Motion but keeps Chorus's LFO. Free-play a chord and press Start Motion for keys if desired. Stop Motion and compare again.
4. **3:00–4:00 — Keep a change.** Adjust a shape or filter. Name it, set useful tags under Author tags and instructions, then Save as new. Favorite it. Rename copy or Duplicate works on your saved copies. Export current sound captures current edits; Export saved preset exports the saved selection. Export a pack as backup.
5. **4:00–5:00 — Blind pass.** Enable Blind labels; keep role, demo phrase, tempo, monitor and register fixed when comparing future banks. Use temporary listening trim only when needed and note its value. Record `keep / uncertain / skip`, what register worked, and a concrete reason. Reveal creator/name afterward with the separate map.

the separately delivered `phosphor-starter-auditions.zip` contains four static WAVs and the pad's explicit Motion WAV, all at 100 BPM / 48 kHz / monitor 0.72, authored trims included, listening trim 0. Files start with one beat of rest and end with the graph tail. They are not normalized. Each role uses its own phrase; don't rank musical quality across roles by level. The [reveal mapping](../../contributor-kit/starter-reveal.json) is separate.

Please listen for useful tone, comfortable register, attacks and releases, chord balance, motion usefulness, and mono color. Chromium checks establish bounded, reproducible behavior in these fixtures; headphones, speakers, Safari and an iPhone still need owner testing.
